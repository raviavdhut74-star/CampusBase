# CampusBase v2
Open `index.html` (ya kisi bhi static hosting - Vercel/GitHub Pages - var upload kara).

- Login / Register: PRN number + password
- Left ☰ menu: sagle options (Premium nahi - nantar)
- Profile: 👤 icon kiva bottom nav "Profile"
- Instagram / WhatsApp / Telegram: OFF. Chalu karayla `index.html` madhe top la `SOCIAL` config madhe `on:true` ani `url` taka.
- Admin: login page var "Master Login" -> "Admin register". Admin code index.html madhe `ADMIN_CODE` (badla!). Sirf 2 admin register hotat. Admin login zalyavar "Upload Files" disto (sagle file types upload/delete). Normal users la nahi.
- Demo mode: data browser madhe save hoto. Real database sathi Supabase (purvicha CampusBase.zip madhla setup.sql) jodava lagel.
